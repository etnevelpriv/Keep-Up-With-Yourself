GitHub Copilot: Completed: *Jelenlegi rules feltérképezése* (1/4)

A Firestore security rules-ben a `matches()` egy string-metódus: reguláris kifejezéssel (regex) ellenőrzi, hogy a string illeszkedik-e a mintára, és `true/false`-t ad vissza.

- **Szignatúra:** `someString.matches("regex") -> bool`
- **Regex motor:** RE2-szerű (nincs lookahead/backreference, stb.).
- **Fontos:** a minta a *teljes* stringre értendő (ezért szokás `.*`-ot használni, ha “tartalmazza” jellegű feltételt akarsz).

A te esetedben:

- `value.matches('.*\\S.*')`
  - `\\S` = “nem whitespace” karakter (a `\S` regex-nek felel meg; rules stringben ezért kell duplázni a backslash-t)
  - `.*` = bármi, bármennyi karakter
  - Jelentés: **van benne legalább 1 nem-szóköz karakter**, tehát a `"   "` (csak space) elbukik, az `"a"`, `"a b"`, `"  a  "` átmegy.

- `value.matches('.*@.*')`
  - Jelentés: **tartalmaz egy `@` jelet** (kb. a TS `includes("@")` rules-os megfelelője).

Ha akarod, lefuttatom a `npm run test:emulator`-t is, hogy a rules szintaxis + integrációs tesztek biztosan zöldek legyenek.
